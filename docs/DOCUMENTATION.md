## 🚀 Quick Start

1. **Install Dependencies:**
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

2. **Install LLVM** (See LLVM_INSTALLATION_GUIDE.md)

3. **Start Server:**
   ```bash
   python start_server.py
   ```

4. **Open Web Interface:**
   - Open `frontend/pages/app.html` in browser
   - Upload C/C++ code
   - Click "Start Obfuscation"
   - Download obfuscated code and HTML report with password
